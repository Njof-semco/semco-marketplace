# semco-azure-devops

Remote Azure DevOps MCP server for `semcomaritime`, read-only (`X-MCP-Readonly: true`).

Sign in: after installing, restart Claude, then run `/mcp` or `claude mcp login`, and log in with your Semco Entra ID account in the browser.

Install either this plugin or `semco-azure-devops-write`, not both.
