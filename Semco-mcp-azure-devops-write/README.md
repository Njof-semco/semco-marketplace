# semco-azure-devops-write

Remote Azure DevOps MCP server for `semcomaritime`, with write tools (work items, PRs, pipelines, wiki).

Sign in: after installing, restart Claude, then run `/mcp` or `claude mcp login`, and log in with your Semco Entra ID account in the browser.

Install either this plugin or `semco-azure-devops`, not both.
